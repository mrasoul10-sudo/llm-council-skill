Five minds argue. One verdict decides. پنج ذهن بحث می‌کنند. یک حکم تصمیم می‌گیرد.

LLM Council is a Claude skill that pressure-tests a decision. Five advisors analyse it from different angles, review each other blind, and a chairman writes the verdict. شورای LLM یک اسکیل Claude است که تصمیم‌های مهم را زیر فشار می‌گذارد. پنج مشاور از زاویه‌های متفاوت تحلیل می‌کنند، یکدیگر را ناشناس بازبینی می‌کنند و رئیس شورا حکم نهایی را می‌نویسد.

How a session runsیک جلسه چطور پیش می‌رود

One question goes in. Claude launches sub-agents in the background and shows you only the final verdict in chat.یک سؤال وارد می‌شود. Claude در پس‌زمینه چند ساب‌ایجنت اجرا می‌کند و فقط حکم نهایی را در چت نشان می‌دهد.

  1. Frame the questionقاب‌بندی سؤال

    Claude reads the files you point to, then rewrites your question as one neutral brief that every advisor receives.Claude فایل‌هایی را که معرفی کرده‌اید می‌خواند و سؤال را به یک شرح خنثی بازنویسی می‌کند که همه‌ی مشاورها دریافت می‌کنند.

  2. Five advisors answer in parallelپنج مشاور هم‌زمان پاسخ می‌دهند

    Each advisor sees only the brief and commits fully to its own angle, in 150 to 300 words.هر مشاور فقط شرح سؤال را می‌بیند و با همه‌ی توان از زاویه‌ی خودش پاسخ می‌دهد، در ۱۵۰ تا ۳۰۰ کلمه.

  3. Blind reviewبازبینی ناشناس

    The answers are shuffled and anonymised. Five reviewers say which is strongest, which has the biggest blind spot, and what everyone missed.پاسخ‌ها بُر می‌خورند و بی‌نام می‌شوند. پنج بازبین می‌گویند کدام قوی‌تر است، کدام بزرگ‌ترین نقطه‌ی کور را دارد و همه چه چیزی را جا انداخته‌اند.

  4. The chairman decidesرئیس شورا تصمیم می‌گیرد

    The chairman reads everything and writes the verdict: confidence, agreement, disagreement, a decision, the first move, and what would change the call.رئیس شورا همه چیز را می‌خواند و حکم را می‌نویسد: سطح اطمینان، توافق‌ها، اختلاف‌ها، تصمیم، اولین قدم و اینکه چه چیزی تصمیم را عوض می‌کند.

Full mode (default)حالت کامل (پیش‌فرض)11 sub-agents: 5 advisors, 5 reviewers, 1 chairman. For decisions where a wrong call is expensive.۱۱ ساب‌ایجنت: ۵ مشاور، ۵ بازبین و ۱ رئیس. برای تصمیم‌هایی که اشتباه در آن‌ها گران تمام می‌شود.
Quick modeحالت سریع6 sub-agents, no review round. Add the word quick when you want it cheaper.۶ ساب‌ایجنت و بدون دور بازبینی. برای ارزان‌تر شدن کلمه‌ی quick را اضافه کنید.

Install the skillنصب اسکیل

Pick where you use Claude. The skill is a single folder named llm-council.بسته به جایی که از Claude استفاده می‌کنید یکی را انتخاب کنید. اسکیل فقط یک پوشه به نام llm-council است.

  1. Download the repository (Code, then Download ZIP) and extract it.ریپو را دانلود کنید (Code و سپس Download ZIP) و از حالت فشرده خارج کنید.
  2. Zip only the llm-council folder, so the zip contains llm-council/SKILL.md.فقط پوشه‌ی llm-council را زیپ کنید تا داخل زیپ llm-council/SKILL.md باشد.
  3. In Claude, open Settings, go to Skills, and upload that zip.در Claude به Settings بروید، بخش Skills را باز کنید و آن زیپ را آپلود کنید.
  4. Open a new chat and type council this: followed by your decision.یک چت جدید باز کنید و council this: را بنویسید و بعد تصمیمتان را.

Menu names can differ slightly between the web and mobile apps. Skills need sub-agents to run the full council; without them Claude plays all roles itself and tells you so.نام منوها ممکن است بین وب و موبایل کمی فرق کند. شورای کامل به ساب‌ایجنت نیاز دارد؛ اگر نباشد Claude همه‌ی نقش‌ها را خودش اجرا می‌کند و به شما اطلاع می‌دهد.

  1. Clone the repository.ریپو را کلون کنید. 
    git clone https://github.com/mrasoul10-sudo/llm-council-skill.git
  2. Copy the llm-council folder into your skills folder.پوشه‌ی llm-council را داخل پوشه‌ی اسکیل‌ها کپی کنید. 
    :: Windows (Command Prompt)
xcopy /E /I /Y llm-council-skill\llm-council "%USERPROFILE%\.claude\skills\llm-council"
    # macOS / Linux
mkdir -p ~/.claude/skills && cp -r llm-council-skill/llm-council ~/.claude/skills/
  3. Start a new Claude Code session and ask for a council.یک نشست جدید Claude Code شروع کنید و شورا را صدا بزنید.

To use it in one project only, copy the folder to .claude/skills/ inside that project instead.برای استفاده فقط در یک پروژه، پوشه را به‌جای آن در .claude/skills/ داخل همان پروژه کپی کنید.

Questionsپرسش‌های رایج

Does it cost more than a normal answer?آیا از یک پاسخ معمولی گران‌تر است؟

Yes. Full mode runs 11 sub-agents and quick mode runs 6. Save it for decisions that matter.بله. حالت کامل ۱۱ ساب‌ایجنت و حالت سریع ۶ ساب‌ایجنت اجرا می‌کند. آن را برای تصمیم‌های مهم نگه دارید.

Does it read my files?آیا فایل‌های من را می‌خواند؟

It can look at files you mention and at project notes such as CLAUDE.md, only to give the advisors context. It is instructed never to read or forward passwords, keys or .env files.فقط برای دادن زمینه به مشاورها، فایل‌هایی را که ذکر می‌کنید و یادداشت‌های پروژه مثل CLAUDE.md را می‌بیند. دستور دارد هرگز رمز، کلید یا فایل‌های .env را نخواند یا ارسال نکند.

Can I change the advisors?آیا می‌توانم مشاورها را عوض کنم؟

Yes. The lenses are plain text in SKILL.md. Rename them or rewrite their descriptions, but keep five lenses that genuinely disagree with each other.بله. زاویه‌ها متن ساده در فایل SKILL.md هستند. می‌توانید نام و توضیحشان را عوض کنید، ولی پنج زاویه بمانند که واقعاً با هم اختلاف دارند.

Does the council check facts?آیا شورا درستی واقعیت‌ها را بررسی می‌کند؟

No. It improves reasoning, not accuracy. Check any number that matters before you act on it.خیر. استدلال را بهتر می‌کند، نه دقت داده‌ها را. هر عددی را که مهم است قبل از اقدام خودتان بررسی کنید.

It did not start. What now?اجرا نشد. چه کنم؟

Use an exact phrase such as council this: and check that the skill is enabled in your Skills settings. In a new chat, ask Claude whether the llm-council skill is available.از یک عبارت دقیق مثل council this: استفاده کنید و مطمئن شوید اسکیل در تنظیمات Skills فعال است. در یک چت جدید از Claude بپرسید اسکیل llm-council در دسترس است یا نه.
